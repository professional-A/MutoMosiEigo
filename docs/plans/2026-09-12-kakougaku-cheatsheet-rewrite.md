# 加工学 カンペシート 全面作り直し（記述答案型へ）

**試験：2026/9/14(月) 10:50–11:40（50分）／範囲：除去加工①〜⑥（切削・研削）／A4両面・手書きのみ持込可**

## 背景（なぜ作り直すのか）

現行シートは「公式集」として設計されていたが、**利用者は授業を一度も聞いておらず、切削の基本公式すら意味が取れない**。
さらに前期中間試験の実物（`materials/2026-zenki-matsu-kakougaku/exam-chukan/p1.jpg`, `p2.jpg`）を数えたところ：

| 大問 | 配点 | 形式 |
|---|---|---|
| 1. 鋳造 | 30 | 全問「説明せよ／理由はなぜか／答えよ」 |
| 2. 塑性加工 | 39 | 記述9＋計算3 |
| 3. 接合 | 21 | 全問記述 |
| 4. 正誤＋下線部訂正 | 10 | 記述 |

**全34問中、数値計算は3問のみ（約9点）。残り90点は日本語の文章で答える。**
現行シートは紙面の約6割を公式（τs, σs, τt, σt の応力4式、力の分解、切れ刃角度記号）に使っており、配点1割の領域に紙面6割を割いている。これが設計ミス。

### 根拠（リサーチ）

- 入門レベルの科目ではカンペの効きが悪い。原因は「シートに書いていない事実を問われる」から — [Dorsey, ED537423](https://files.eric.ed.gov/fulltext/ED537423.pdf)
- カンペが得点を上げるのは Bloom の **comprehension レベルの設問のみ**。今回の「〜を説明せよ」はまさにこの層 — [Shaffer et al. (2016)](https://people.cs.vt.edu/shaffer/Papers/Crib_Sheets2016.pdf)
- 図・抽象表現・整理されたブロック配置は得点と正の相関。情報密度の高さは負の相関 — Ludorf & Clark (2014), de Raadt (2012)
- 既存 finding `research/findings/short-term-exam-prep.json` → `cheatsheet-content-what-correlates-with-scores` の caveat：「知識ゼロの学習者が単に量を減らしても点は上がらない」
- 本番と同じ形式で練習・準備するほど転移する（同ファイル `match-the-language-of-the-real-exam`）

**結論：シートを「公式集」から〈答案にそのまま書き写せる文のストック〉に変える。**

## 設計原則（実装者はこれを守ること）

1. **各項目は「問われ方 → 書き写す文」の対で書く。** 単語の羅列にしない
   ```
   Q 自生作用とは何か説明せよ
   A 砥粒が摩耗すると脱落し、内側の新しい砥粒が切れ刃として
     現れるため、切れ味が維持される作用。
   ```
2. **A の文は句点まで完成した日本語にする。** 試験中に組み立てさせない。長さは1〜3文
3. **記号を使う場合は必ずその場で意味と単位を書く。** 「別の場所を見ろ」を作らない
4. **図は残す。** 現行の7点の SVG は得点と正の相関がある唯一の要素なので、削らない
5. 情報密度を上げない。切る判断を恐れない（下の「切るもの」参照）
6. 番号は書く優先順位。上から書けば途中でやめても損失が最小

## 切るもの（紙面を空ける）

- せん断面・すくい面の応力4式：`τs`, `σs`, `τt`, `σt`
- せん断面積：`ls=d/sinφ`, `As=db/sinφ`
- 切れ刃角度の記号5つ（αf, γf, αp, γp, φ アプローチ角）→ 一行にまとめて最低優先度の枠へ
- `rc = sinφ/cos(φ-α)` の別表現（`rc=d/t` だけ残す）

## 残す公式（計算は2〜3問と見込む）

| 式 | 用途 |
|---|---|
| `V=πDN/1000`, `N=1000V/(πD)` | 切削速度・回転数。V:m/min, D:mm, N:rpm |
| `F=fN` | 送り速度。F:mm/min, f:mm/rev |
| `Rz=f²/(8R)` | 表面粗さ。f:送り量mm, R:コーナ半径mm |
| `tanφ=rc·cosα/(1-rc·sinα)` | せん断角 |
| `γ=tan(φ-α)+cotφ` | せん断ひずみ |
| `Fs`, `Fn`, `F`, `N`, `μ=F/N=tanβ`, `R=Fc/cos(β-α)` | 力の分解（図とセット） |
| `Pc=ap·ae·Vf·Kc/(60×10⁶·η)`, `fz=Vf/(NZ)` | 切削動力。計算例つき |
| `g=2a(v/V)√{t(1/D+1/d)}`, 平面研削は `√(t/D)` | 研削の最大切り取り厚さ |

**公式は「使い方の一行」を必ず添える。** 例：`Rz=f²/(8R)` → 「送りfを半分にすると粗さは1/4。Rを大きくしても粗さは小さくなる」

### 正誤・下線部訂正対策（中間の第4問と同形式）

「混同しやすいペア」ブロックは現行のまま残す。ただし**訂正しやすいように「誤りやすい語 → 正しい語」の向きで書く**こと。例：
```
「目つぶれ＝砥粒の脱落」→ 誤。脱落は目こぼれ。目つぶれは摩耗
「ツルーイング＝目出し」→ 誤。目出しはドレッシング
「研削のすくい角は正」→ 誤。大きな負のすくい角
```

## 紙面配置

現行の2シート×2カラムのブロック構造・CSS・SVG をそのまま使う。中身を差し替える。

```
┌─── 表面（切削）──────────────┐  ┌─── 裏面（研削）──────────────┐
│ ① 記述Q&A 基礎  │ ③ 公式A    │  │ ① 記述Q&A 砥粒 │ ② 自生作用Q&A  │
│   (Q1〜6)      │   +図(旋削/ │  │   (Q19〜25)   │   +3不具合(Q26  │
│                │    粗さ)    │  │               │    〜28)+4コマ図 │
│ ④ 運動の表(Q7) │ ③ 公式B    │  │ ④ 研削機構     │ ③ 公式C(g)+図   │
│ ⑤ 工具材料     │   +力の図   │  │   (Q29〜31)   │                 │
│   (Q8〜11)     │            │  │               │ ⑤ 計算例        │
│ 図 切削の幾何   │ ② 記述Q&A  │  │ ② 混同ペア     │ 【氏名】        │
│                │   力(Q12〜17)│  │   (正誤対策)   │                 │
│ 余 予備スペース │ 余 バイト   │  │               │                 │
└──────────────────────────┘  └──────────────────────────┘
```

優先順位（`num` バッジの数字）：
- **①＝記述Q&A**（配点9割の領域）と **②** — 何があっても書く
- **③＝公式と図**
- **④⑤** — 書ければ書く
- **余** — 余力があれば

書き出しの指示（`.note`）は「**まず裏面右下の氏名欄の枠を引く → ①のQ&Aから書く**」に変更する。現行の「図は飛ばさないこと」の注意書きは残す。
