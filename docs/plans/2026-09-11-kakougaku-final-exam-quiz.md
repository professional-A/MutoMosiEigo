理由は制御工学の仕様書と同じ。本番が記述式なので**生成は紙の上でやらせ**、

## 誤選択肢の作り方

**適当なダミーで埋めない。** 1つ1つを特定の誤りに対応させ、解説でそのミスを名指しする。

| 題材 | 正解 | 誤選択肢に仕込むミス |
|---|---|---|
| 目つぶれ／目こぼれ／目づまり | それぞれの定義 | 3つを互いに入れ替える（最頻出の混同） |
| ツルーイング／ドレッシング | 整形／目出し | 2つを入れ替える |
| $V=\pi DN/1000$ | — | 1000を掛ける版、$\pi$ 抜け、$N$ と $D$ の入れ替え |
| $Rz=f^2/(8R)$ | — | $f^2/(4R)$、$f/(8R)$、$8R/f^2$ |
| 研削の $g$ | 円筒 $2a\frac{v}{V}\sqrt{t(1/D+1/d)}$ | $\sqrt{}$ の範囲違い、$1/D-1/d$、$v/V$ の逆数 |
| 切削比 $r_c$ | 切込み$d$／切屑厚さ$t$ | 逆数（切屑厚さ／切込み）、$0.3$ を $3$ |
| 切削と研削の切屑厚さ | 切削0.05mm／研削μm未満 | 逆にする |
| 切削と研削の速度 | 切削200／研削2000 m/min | 逆にする、桁違い |

# 収録内容（範囲の全項目・これ以外を出さない）

## 除去加工①（加工学09）
- 生産加工の分類：変形加工／付加加工／除去加工
- 除去加工の特徴：材料を削り取り形を作る／切屑が出る／高い精度／長い加工時間
- 除去加工の種類：①切削（刃物）②研削（砥粒）③高エネルギ（放電・レーザ）
  ④その他（溶融・気化・酸や電気分解で溶かし出す）。例）エッチング＝保護膜の無い部分を腐食液で溶かす（集積回路）
- 機械加工（Machining）＝工作機械（Machine Tool）で所望の形状寸法の機械部品に加工する作業
- **マザーマシン：工作機械の精度 ≧ 加工部品の精度**
- 切削の3要素（重要）：①工作機械 ②切削工具 ③切削条件
- 切削加工の特徴：切屑（Chip）が排出される／3要素の組合せで多様な形状

## 除去加工②（加工学10）
- 旋削加工の種類、バイトの種類
- 切削条件（①切削速度 ②送り速度 ③切込み量）
  → バイトの種類・形状で適正値が異なる／加工時間・加工精度・工具寿命を決める
  - $V=\pi DN/1000$、$N=1000V/(\pi D)$（$V$:m/min、$D$:mm、$N$:rpm）
  - $F=fN$（$F$:mm/min、$f$:mm/rev）
  - $d$：切込み量（mm）
- 加工面の表面粗さ：幾何学的理論粗さ（送りマーク）
  - $Rz=R(1-\cos\theta)$ から導出して $\boxed{Rz=f^2/(8R)}$
  - $Rz$:最大高さ、$f$:1回転当たりの送り量、$R$:バイトのコーナ半径

## 除去加工③（加工学11）切削理論①
- バイトの各部：(1)すくい面 (2)主逃げ面 (3)副逃げ面 (4)主切れ刃 (5)副切れ刃 (6)コーナ (7)シャンク
- 切れ刃角度：$\alpha_f$サイド逃げ角／$\gamma_f$サイドすくい角／$\alpha_p$バック逃げ角／$\gamma_p$すくい角／$\varphi$アプローチ角
- 切削工具に要求される特性：①切削温度下で被削材より硬い ②耐欠損性（靭性）③耐摩耗性 ④刃先の形状に成形可能
- 工具材料
  - ①炭素工具鋼／合金工具鋼：炭素鋼 C 0.6〜1.4%、合金鋼＝炭素鋼＋Cr,Mo,W,V,Co、焼入れ焼戻し **→靭性向上**
  - ②高速度工具鋼：炭素鋼 C 0.8〜1.6% ＋Cr,Mo,W,V,Co **→高温強度向上**
  - ③超硬合金：WC（炭化タングステン）、TiC（炭化チタン）＋Co（結合材）をプレス成型し焼結（**粉末冶金**）

## 除去加工④（加工学12）切削理論②
- 切りくずの定量的評価：**切削比** $r_c=l_c/l=d/d_c$ ※鋼材で0.3程度（厚く短くなる）
- 切削力＝切削に必要な力（工具側）／**切削抵抗**＝切削の反力 $R$（被加工材側）
- 分力：$F_c$ 主分力（水平分力）／$F_t$ 背分力（垂直分力）／$F_f$ 送り分力
- 切削比とせん断角：$r_c=\dfrac{d}{t}=\dfrac{\sin\varphi}{\cos(\varphi-\alpha)}$、
  $\boxed{\tan\varphi=\dfrac{r_c\cos\alpha}{1-r_c\sin\alpha}}$（$\varphi$:せん断角、$\alpha$:すくい角）
- せん断ひずみ：$\gamma=\tan(\varphi-\alpha)+\cot\varphi$
- すくい面に働く力：$F$摩擦力、$N$垂直力、$F=\mu N$、$\mu=F/N=\tan\beta$（$\beta$:摩擦角）
- せん断面に働く力：$F_s$せん断力、$F_n$垂直力
- $F_s=F_c\cos\varphi-F_t\sin\varphi$／$F_n=F_c\sin\varphi+F_t\cos\varphi$
- $F=F_t\cos\alpha+F_c\sin\alpha$／$N=F_c\cos\alpha-F_t\sin\alpha$
- $R=\dfrac{F_c}{\cos(\beta-\alpha)}=\dfrac{F_t}{\sin(\beta-\alpha)}$
  → 摩擦角$\beta$が既知なら主分力・背分力の測定で$R$が求まる
- せん断面積：$l_s=d/\sin\varphi$、$A_s=l_s b=\dfrac{db}{\sin\varphi}$
- $\tau_s=\dfrac{(F_c\cos\varphi-F_t\sin\varphi)\sin\varphi}{bd}$、
  $\sigma_s=\dfrac{(F_c\sin\varphi+F_t\cos\varphi)\sin\varphi}{bd}$
- すくい面：$\tau_t=\dfrac{F_c\sin\alpha+F_t\cos\alpha}{lb}$、$\sigma_t=\dfrac{F_c\cos\alpha-F_t\sin\alpha}{lb}$
- **切削動力** $P_C=\dfrac{a_p a_e V_f K_C}{60\times10^6\,\eta}$ [kW]
  （$a_p$切込みmm、$a_e$切削幅mm、$V_f$送り速度mm/min、$K_C$比切削抵抗MPa、$\eta$機械効率）
- **比切削抵抗** $K_C$：断面積1mm²の切りくずを切削するのに必要な切削方向の力$F_c$の大きさ
- 1刃当たりの送り $f_z=\dfrac{V_f}{NZ}$（$Z$:刃数）
- 計算例（正面フライス）：$a_p$=2mm、$a_e$=80mm、$V_f$=280mm/min、$V$=80m/min、
  $D$=ø250、$Z$=12、$\eta$=0.8 → $N$=101.91rpm、$f_z$=0.229mm/tooth、$K_C$=1800MPa、$P_C$=1.68kW

## 除去加工⑤（加工学13）研削①
- 砥粒加工：砥粒（Abrasive Grain）による極微小な切削で目的の表面・寸法・形状を得る
- 特徴：①高硬度材料の加工が可能 ②砥粒1刃当たりの切削量が少ない（切削0.05mm、研削μm未満）
  →③高精度の加工に適する →④加工効率が悪い（切削加工後に加工） ⑤切れ味が維持される（自生作用）
- 分類：**固定砥粒**（砥石＝砥粒を結合剤で固める・角型/丸型、研摩シート＝砥粒を結合剤でシートに固定）／
  **遊離砥粒**（研磨シート、超音波、バフ仕上げ）
- 切込み方式：**強制切込み**（丸型砥石・角型砥石→研削加工）／**定圧切込み**（ホーニング、超仕上げ、ベルト研削）
- 研削（Grinding）
  - ①円筒研削：砥石回転＋工作物回転
    - **トラバース加工**：切込み後、回転軸方向に往復移動
    - **プランジ加工**：切込みのみ、回転軸方向の移動なし
  - ②平面研削：砥石回転＋工作物直線運動

## 除去加工⑥（加工学14）研削②
- 砥石の再生
  - **ツルーイング（Truing／整形）**：砥石の重心を回転中心に調整
  - **ドレッシング（Dressing／目出し）**：砥粒を結合剤から突出させる
- **自生作用（self-sharpening）**：砥粒が摩耗→脱落→次の砥粒が切れ刃となる
- 自生作用が働かない場合
  - **目つぶれ（Dulling）**：砥粒の摩耗
  - **目こぼれ（Shedding）**：砥粒の過剰な脱落
  - **目づまり（Loading）**：砥粒間の空孔のつまり
- 研削機構（多数の砥粒毎に加工工程が混在）
  - ①切れ刃がランダムな形状・分布 →統計的な扱いを要する
  - ②大きな**負のすくい角**で切削。砥粒1個の切屑厚さが微小（切削0.05mm〜／研削μm未満〜）
  - ③研削速度が著しく大きい（切削：超硬工具200m/min／研削：2000m/min→**冷却が必要**）
- **研削による最大切り取り厚さ** $g$
  - 円筒研削：$g=2a\dfrac{v}{V}\sqrt{t\left(\dfrac{1}{D}+\dfrac{1}{d}\right)}$
  - 平面研削（$d=\infty$）：$g=2a\dfrac{v}{V}\sqrt{\dfrac{t}{D}}$
  - $D,d$:砥石・工作物の直径、$V,v$:周速、$t$:半径方向切込み深さ、$a$:砥粒間隔
  - ※単位幅の2次元切削を仮定（実際の砥粒の切削幅より大幅に大きいことに注意）
  - **$g$大＝砥粒の負荷大＝砥粒は脱落（過度なら目こぼれ）**
  - **$g$小＝砥粒の負荷は小＝砥粒は摩滅摩耗（目つぶれ）**
