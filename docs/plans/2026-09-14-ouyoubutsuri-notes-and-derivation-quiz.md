# A. `ouyoubutsuri-notes.html` の作り直し

## 現状の問題（実測して診断済み）

元は利用者が作った29枚のPPT。それをHTML化した結果、**11,078px の連続スクロール**になっている。
バグではなく設計の問題で、原因は2つ。

**① 1スライド＝1アイデアの区切りが消えた**
例：シュレディンガーの導出①②③は、元は**スライド20・21・22の3枚**。
それが1枚の `.op-card` に圧縮され、①②③が行頭の太字に格下げされている。

**② 階層が反転している**
数式は `.op-eq`（枠付き・`1rem`〜`1.08rem`）で目立つのに、
理解の核である解説文は `.op-callout`（`.82rem` ＋ `var(--muted)` の灰色）で、
**ページ内で最も読みにくい要素**になっている。元PPTでは解説が主役だった。

**③ 導出の順序が消えた**
`.op-eq-row` が `display:flex` で数式を横並びにするため、
「→ だから → だから」という導出の順序が、無関係な箱の列に見える。
**今回の試験は導出の順序そのものを問う形式**なので、これは最悪の相性。

## 直し方

1. **`.op-eq-row` の横並びをやめる。** 導出は必ず縦に積む。
   1ステップ ＝「なぜそうなるかの一文」＋「数式1つ」を縦のペアにする。
   横並びを使ってよいのは、対等な2式を**並置して比較させる**ときだけ（例：光と電子の対応）

2. **階層を戻す。**
   - `.op-callout` の本文を `.82rem` → `.92rem`、色を `var(--muted)` → `var(--ink)`
   - `.op-card ul` の本文も `.87rem` → `.93rem`
   - 逆に `.op-eq` の枠の主張を下げる（背景と枠線のコントラストを弱める）
   - 数式が主役ではなく、**文章が主役で数式が従**、という見え方にする

3. **元PPTの1スライド＝1カードに分割し直す。**
   特に SECTION 07（シュレディンガー方程式）は、現在1〜2カードに詰め込まれている
   ①|ψ|²が一定になる極限 ②時間微分→エネルギー演算子 ③空間2階微分→運動量演算子 ④方程式の完成
   を、**それぞれ独立したカードに分ける**。SECTION 08（井戸型ポテンシャル）も同様に
   モデルの設定／内部・外部の解／境界条件から連立／エネルギー準位の量子化 に分ける

4. **各導出カードの先頭に「穴埋めで問われる箇所」の印を付ける。**
   `.op-eq` のうち、本番で（ア）（イ）として抜かれそうな式に小さなバッジを付け、
   クイズページへのリンクを各セクション末尾に置く

5. **セクション間に区切りを入れる。** 現状はカードが等間隔で続くので、
   どこで話題が変わったのかが分からない。`.op-section` の上マージンを増やし、
   セクション冒頭に現在地（8つ中の何番目か）を出す

## やってはいけないこと

- 内容を削らない・要約しない。これは利用者が自分で作ったノートで、**中身は正しい**。直すのは見せ方だけ
- KaTeX の式を画像に置き換えない
- `materials/` の画像を参照しない（gitignore 済み・`express.static` で全公開されるため）
- `theme.css` の `:root` を汚染しない。ローカル変数は `.op-wrap` にスコープする
- ハンバーガーメニュー（`appShell.mount`）を壊さない

## 設問の作り方

- **全問 `single`。** 記述・数値入力は作らない。本番に無いから
- **1つの導出を、順番に並んだ連続した穴埋めに分解する。** 順番をバラさない。
  本番が「導出を文章で書き下して途中式を抜く」形式なので、それを再現する
- 問題文は**本番と同じ日本語の書き下し**にする。
  例：「ここで、微小部分の質量 dm は（ア）となる。（ア）に当てはまるものとして
  最も適切なものを次の選択肢から選びその番号にマークしなさい。」
- 選択肢は4〜5個。**上の表の4型（係数・次数・積分要素・符号）で作る**
- ただし紛らわしい選択肢は **1問につき2つまで**。残りは明らかに違うものにする
  （`optimal-difficulty-85-percent` の caveat：紛らわしすぎると正答率が下がりすぎて逆効果）
- 各問に**即時フィードバックと解説**を必ず付ける。解説には
  「なぜ他の選択肢が違うか」を1行入れる（`competitive-lures-make-mcq-generative`）
- 各導出につき、**表層を変えた類題を1本**（`vary-surface-keep-deep-structure`）。
  例：トムソンの e/m を「別の装置寸法」で、井戸型を「幅 L → 2L」で
