## 2. flashcard の仕様

`js/quiz-engine.js` の flashcard 分岐を必ず読むこと。確認済みのフィールド：

```json
{ "type": "flashcard", "tag": "U3 Word List", "front": "表面（HTML可）", "back": "裏面（HTML可）" }
```

- 表面をタップで裏面表示、「覚えた」で `1`、「まだ」で `0`
- `tag` は表面の上に小さく出る。**Unit と区分を入れる**（例：`U4 ・ Word List ・ 名詞`）
- `front` / `back` は `innerHTML` で描画される。`<b>` `<br>` `<span>` を使ってよい
- flashcard は選択肢を持たないので `prepareQuestions` のシャッフル対象外。`opts`/`ans`/`note` は不要

### カードの書き方（全ステップ共通）

- **表面は「思い出す手がかり」だけ。** 答えのヒントを表面に書かない
- **裏面は1枚で完結させる。** 意味だけで終わらせず、試験で問われる形の情報まで載せる
- 裏面の構成（該当するものだけ）：
  1. **答え**（太字で1行目）
  2. 英英定義（Word List の原文ママ）
  3. **本文での使われ方**（[L.xx] と短い引用1文まで。全文を載せない）
  4. **注意**：派生語・品詞違い・綴りの罠（`current` ≠ `currently`、`embed` の綴り、`groundwater` はリストで `groudwater` と誤植）
- 同じ語を方向違いで複数枚作ってよい（英→日と日→英は別カード）

## 6. vocabtest4（本番形式）の input 置き換え

Unit 3 語彙テストの Q2 は「英単語を書く」形式だったが、**選択式で代える**。

- **Q2形式セクション（30問）**：表示は実物と同じ「日本語＋英英定義」。
  選択肢は **正しい綴り1つ＋綴り・派生語の罠3つ**
  例：電流／a flow of electricity → `current`（正）／`currently`／`currency`／`curent`
  問題文の冒頭に「**紙に綴りを書いてから選択肢を見てください**」
- **弱点セクションは作らない**（0章）。句動詞の空白（`soakup`／`soak up`）や `groundwater`／`groudwater`（リストの誤植）は Q2形式の罠として使う
- 誤選択肢の綴りミスは、**実際にありそうなものだけ**（1文字抜け・重複・母音違い）。でたらめな文字列にしない
- 全問 `note` に「なぜ他が違うか」
