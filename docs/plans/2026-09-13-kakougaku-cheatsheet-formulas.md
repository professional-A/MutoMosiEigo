# 加工学カンペシート 公式ブロックの作り直し（ゼロ知識対応）

前提：`docs/plans/2026-09-12-kakougaku-cheatsheet-rewrite.md` で記述Q&A化は完了済み。
**今回は公式ブロックだけを直す。記述Q&Aブロック・混同ペア・氏名欄は触らない。**

## 問題

記述Q&Aは「読めばそのまま答案に写せる」状態になったが、公式ブロックは記号の羅列のままで、
**ある程度の理解を前提に組まれている**。

```
V=πDN/1000  N=1000V/(πD)  V:m/min D:mm N:rpm
```

利用者は授業を一度も聞いていない。この行を見ても
「V は何の速さか」「D はどこの直径か」「なぜ 1000 で割るのか」が分からず、使えない。
**単位の羅列は定義ではない。**

## 方針

公式ブロックを**図が主・式が従**の構成に変える。3点セットを守る：

1. **図** — その記号が実際にどこを指すのかを、図の上に矢印とラベルで示す
2. **日常語の意味** — 「V＝刃が材料の表面をなぞる速さ」のように、専門用語を使わず言い換える
3. **なぜその式になるか、一行** — 丸暗記させない。特に単位換算の理由

例（`V=πDN/1000` の場合）：

```
V = πDN/1000
 直径D[mm]の円周は πD[mm]。それが1分間にN回まわるから
 刃の進む距離は πDN [mm/min]。m/min にしたいので 1000 で割る。
 V:切削速度=刃が材料の表面をなぞる速さ[m/min]
 D:工作物の直径[mm]  N:回転数[回/min=rpm]
```

### 記号の衝突（必ず注意書きを入れること）

利用者が最も事故りやすい箇所。該当する図のそばに赤字で書く。

- **d** ＝ 旋削では「切込み量」、研削の g の式では「工作物の直径」
- **D** ＝ 旋削では「工作物の直径」、研削では「砥石の直径」
- **V / v** ＝ 研削では大文字が砥石の周速、小文字が工作物の周速
- **R** ＝ 粗さの式では「バイト先端の丸み半径[mm]」、力の式では「切削抵抗[N]」
- **t** ＝ 切削理論では「切屑の厚さ」、研削では「切込み深さ」
- **φ** ＝ 切削理論では「せん断角」、バイトの角度では「アプローチ角」

## 図（SVG）の作業

既存7点はすべて維持。**ラベルを増やす**のが主作業。`svg text` は 7px なので、
ラベルが増えて潰れる場合は viewBox を広げて対応する（拡大縮小は CSS 側で効く）。

### 1. 旋削図（既存・大幅に描き直す）
現行は 100×52 の小図で D/N/f/d のラベルが最小限。**表面の公式Aブロックの主役にする。**
- 工作物の円柱を横から見た図にし、直径 D・回転方向 N の矢印を明示
- バイトを描き、軸方向へ進む矢印に f（1回転あたり）と F（1分あたり）を併記
- 半径方向に食い込む深さ d を寸法線で示す
- 刃先が材料表面をなぞる向きに V の矢印
- 図の下に「πD＝円周」「×N回/min」「÷1000でm/min」の3段の帯を描き、単位換算を目で追えるようにする

### 2. 表面粗さ図（既存・ラベル追加）
- f＝送りマークの山どうしの間隔、R＝円弧の半径、Rz＝山と谷の高さの差 を明示
- 「fを半分にすると Rz は1/4」を図の注記に

### 3. 切削の幾何図（既存・ラベル追加）
- α（工具上面の傾き）、φ（せん断面の傾き）、d（元の層の厚さ）、t（切屑の厚さ）
- 「切屑は厚く短くなる → rc = d/t < 1、鋼で約0.3」を図中に

### 4. 力の図（既存・Fs/Fn を追加）
現行は R, Fc, Ft, F, N のみ。**せん断面上の Fs, Fn を描き足す。**
- せん断面（角度φ）を破線で描き、そこに沿う Fs と垂直な Fn
- すくい面（角度α）上の F（摩擦）と N（垂直）
- 「直接測れるのは Fc と Ft だけ。他は全部この図から角度で分解して出す」を注記

### 5. フライス図（**新規**）
`Pc` と `fz` の式に対応する図が存在しないのが最大の穴。計算例もこの式を使う。
- 正面フライス（円盤に刃が Z 枚）を描く
- 工作物に対する切込み ap（深さ方向）と切削幅 ae（横方向）を寸法線で
- テーブルの送り Vf の矢印
- 「刃1枚あたりの送り fz = Vf/(NZ)」を図の横に

### 6. 研削の g 図（既存・ラベル追加）
- 砥石 D と工作物 d を明示（**d が直径であることを赤字で注記**）
- V（砥石の周速）と v（工作物の周速）を別の色で
- t（半径方向の切込み深さ）と a（砥粒の間隔）を拡大吹き出しで描く
- g（砥粒1個が削る最大厚さ）を拡大部分に

### 7. 4コマ砥石図・トラバース/プランジ図
そのまま維持。変更しない。

## ブロック構成の変更

### 予備スペース → 「記号早見表」に置き換える（表面 左下）

現行の予備スペースブロックは空欄の案内文しか入っていない。ここを潰して、
上の記号一覧のうち**混同しやすいものだけ**を表にする。全部は入らないので優先順位は：

1. 記号の衝突6件（d/D/V/v/R/t/φ）— 最優先
2. V, N, f, F, d の意味と単位
3. α, φ, rc
4. Fc, Ft と「測れるのはこの2つだけ」
5. ap, ae, Vf, Z, fz, Kc, η

### 公式Aブロック（表面 右上）
旋削図を主役に置き、式は図の下に。`V=πDN/1000`, `N=1000V/(πD)`, `F=fN` と単位換算の説明。

### 公式Bブロック（表面 右）
`rc`, `tanφ`, `γ` と力の分解。幾何図と力の図をこのブロックに入れる。
Pc と fz は公式Bから**外して**、新しい「公式D ─ フライスと動力」ブロックへ移す。

### 公式D ─ フライスと動力（**新規**・裏面 右、計算例の直前）
フライス図＋`Pc=ap·ae·Vf·Kc/(60×10⁶·η)`＋`fz=Vf/(NZ)`。
すぐ下の計算例ブロックと縦に並べ、図→式→数値例の順に目が動くようにする。

### 計算例ブロック（裏面 右下・書き換え）
現行は数値だけが並んでいる。**各行に「何を求めているか」を日本語で付ける。**
```
【例】正面フライス ap=2mm ae=80mm Vf=280mm/min
      V=80m/min D=ø250mm Z=12枚 η=0.8
① まず回転数 N を出す（V と D から）
   N=1000×80/(3.14×250)=101.9 rpm
② 刃1枚あたりの送り fz（刃が何枚で分担するか）
   fz=280/(101.9×12)=0.229 mm/tooth
③ 材料と条件から Kc を表で読む → 1800 MPa
④ 動力 Pc に代入
   Pc=2×80×280×1800/(60×10⁶×0.8)=1.68 kW
```

### 公式Cブロック（裏面 右）
研削図を主役に。**d が工作物の直径であること・平面研削は d=∞ だから 1/d が消えて `√(t/D)` になること**を明記。

## 追記：記述Q&A側に漏れている記号参照（今回あわせて直す）

監査したところ、記述Q&Aブロックの**答えの文そのものが記号に依存している**箇所が5つある。
ここは「読んで写せばいい」が成立していない。該当のQの行末に、参照すべき図の名前を入れる。

| 箇所 | 記号 | 対応 |

| Q12 切削比 rc が1より小さくなる理由 | rc, d, t | 行末に「→切削の幾何図」 |
| Q15 比切削抵抗 Kc とは何か | Kc, Fc | 行末に「→フライス図・力の図」 |
| Q16 Fc・Ft の測定で R が求まる理由 | β, α, Fc, Ft, R | 行末に「→力の図」 |
| Q17 送り f を小さくすると粗さはどうなるか | Rz, f, R | 行末に「→粗さ図」 |
| Q31 g が大きい場合・小さい場合 | g | 行末に「→研削の g 図」 |

混同ペアブロックの以下2行も同様に記号依存なので、同じ扱いにする。
- 「g大=負荷大=脱落(目こぼれ) / g小=負荷小=摩滅(目つぶれ)」→ 研削のg図
- 「すくい角 切削=正 / 研削=大きな負」→ 切削の幾何図

**参照先は必ず同じ面（表なら表、裏なら裏）に置くこと。** 紙を裏返させない。
